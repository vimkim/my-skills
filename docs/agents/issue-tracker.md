# Issue tracker

Use GitHub Issues in vimkim/my-skills through the gh CLI.
Pass --repo vimkim/my-skills explicitly.

- Publish specs and tickets as issues.
- Read issue bodies, labels, and comments before working.
- Use --body-file for multiline issue bodies and comments.
- Apply labels according to triage-labels.md.
- Represent blocking relationships with native issue dependencies.
  If unavailable, record “Blocked by: #N” in the issue body.

PRs as a request surface: no.
